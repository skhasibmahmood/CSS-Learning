# CSS Fundamentals | Learning & Practice

A hands-on CSS learning repository documenting my practical exercises in styling web interfaces and understanding layout fundamentals.

This project builds on my HTML foundation and supports my journey toward becoming a UI/UX Engineer.

## Learning Overview
- **Technology:** CSS3
- **Code Editor:** Visual Studio Code
- **Foundation:** HTML5
- **Version Control:** Git & GitHub
- **Status:** In Progress

## Topics Practiced

- **CSS Fundamentals:** External CSS Integration, Comments, Selectors
- **Colors & Backgrounds:** Text Color, Background Color, Background Images
- **Typography:** Font Size
- **Box Model:** Content, Padding, Border, Margin
- **Spacing:** Margin vs Padding
- **Dimensions:** Width, Height & Box Sizing
- **Borders & Outlines:** Border Properties, CSS Outline

## Learning Goal

To strengthen my understanding of CSS and translate visual design concepts into structured, responsive web interfaces as a UI/UX Engineer.
